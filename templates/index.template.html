    Sync from Apple Health

    Checking for synced data…

    Apple Health has no web link, so your iPhone sends the numbers to this page. Two ways to do it:

    Option A: Health Auto Export app (easiest, runs by itself)

    1. Install Health Auto Export on your iPhone and allow Health access.
    2. Add an Automation with type REST API, format JSON.
    3. Paste the web address and header below. Choose Step Count, Weight, Resting Heart Rate, Sleep Analysis and Blood Pressure, with a daily or hourly schedule.

    Option B: Apple Shortcuts (free, no extra app)

    1. In Shortcuts, add Find Health Samples (for example Steps, today), then Calculate Statistics → Sum.
    2. Add Get Contents of URL: method POST, JSON body {"entries":[{"date":"2026-10-03","metric":"steps","value":8000}]} using the Sum and today’s date.
    3. Add the header below. In Automation, run it every evening.

    Keys for this profile

      Each key only adds numbers to this profile, never reads health records. Metrics you can send: weight, steps, resting_hr, bp_sys, bp_dia, sleep, body_fat. Revoke a key if a phone is lost.
